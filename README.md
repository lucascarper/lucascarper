## ▌ Sobre mim

Trabalho na fronteira entre **desenvolvimento de software** e **análise de dados**. Gosto de construir o sistema inteiro: puxar o dado da fonte, tratar, guardar num banco de verdade e entregar numa tela ou num e-mail que alguém consiga usar sem pedir explicação.

- Integro sistemas por **API REST** e transformo o que chega em informação confiável: eventos, métricas e relatórios automáticos.
- Faço **ETL com Python e pandas**, valido os números com **SQL puro** antes de publicar um dashboard e documento as decisões de limpeza.
- Desenvolvo **backends** em FastAPI e Django, com testes, migrações, Docker e deploy na Railway.
- Prefiro regra de negócio isolada e testável, e decisão registrada por escrito (ADR) a regra escondida no código.

```python
class Lucas:
    foco = ["desenvolvimento", "análise de dados"]
    principio = "se não dá pra conferir o número, ele não vai pro painel"
    stack_principal = ["Python", "SQL", "FastAPI", "Django", "pandas", "PostgreSQL"]
```
